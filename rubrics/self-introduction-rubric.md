# Self-Introduction Rubric (AI Interviews) / 自我介绍评分量表（AI 面试）

This rubric scores an interview self-introduction (opening pitch) for AI roles.

本量表用于评估 AI 岗位面试开场自我介绍的质量。

## 1) Scoring System / 评分区间

Use a 1-5 scale to measure professionalism, technical depth, and role alignment.

使用 1-5 分衡量专业度、技术深度和岗位匹配度。

- 5 (Excellent) / 卓越：逻辑强、信息密度高、亮点独特、可被追问验证
- 4 (Good) / 良好：表达清晰、与岗位高度匹配
- 3 (Qualified) / 合格：满足基本要求，背景清楚但亮点一般
- 2 (Needs Improvement) / 待提升：重点不突出、结构混乱或空泛
- 1 (Unqualified) / 不合格：表达无序、明显不匹配或存在虚假风险

## 2) Campus Hire Dimensions / 校招维度（潜力、理论、科研）

| Dimension | Weight | Key Indicators | 中文解读 |
| :--- | :---: | :--- | :--- |
| Research Potential | 35% | Top papers, lab projects, awards | 科研动机、贡献、结果是否讲得清 |
| Theoretical Foundation | 25% | ML math, DL internals | 对原理是否理解到位，不止背概念 |
| Engineering Skill | 20% | Frameworks, code quality, pipelines | 工程实操与训练/推理链路经验 |
| Logic & Delivery | 10% | Structure, pacing, confidence | 2 分钟内结构完整、节奏好 |
| Drive & Passion | 10% | SOTA awareness, curiosity | 对前沿方向有持续关注和思考 |

## 3) Experienced Hire Dimensions / 社招维度（影响、系统、洞察）

| Dimension | Weight | Key Indicators | 中文解读 |
| :--- | :---: | :--- | :--- |
| Project Depth | 35% | Hard problems, architecture, tradeoffs | 复杂度、决策逻辑、取舍是否讲清 |
| Impact & Value | 25% | ROI, latency, cost, quality, stability | 是否量化结果，是否对业务有价值 |
| Technical Breadth | 20% | End-to-end awareness | 是否具备全链路视角（数据-训练-评测-上线） |
| Leadership/Influence | 10% | STAR, cross-team, mentorship | 是否体现影响力与协作能力 |
| Culture Fit | 10% | Motivation, clarity | 动机是否清晰理性，能否对上团队需求 |

## 4) Red Flags / 负面信号

1. \"API caller\" / 调包倾向：解释不清底层原理或工程细节
2. Lack of focus / 缺乏重点：讲很久讲不到核心工作
3. Ambiguous contribution / 贡献不清：反复用“我们”但个人角色不明确
4. Contradictions / 前后矛盾：简历数据与口述无法自洽
5. Arrogance / 态度问题：抗拒质疑、缺少开放讨论心态
