# Mock Interview Flow Skill / Mock 面试流程 Skill

Use this skill to design and run a realistic interview simulation.

## Standard AI Interview Loop

- Recruiter screen: 20-30 minutes.
- Hiring manager or technical screen: 45-60 minutes.
- Coding screen: 45-60 minutes.
- ML fundamentals or research deep dive: 45-60 minutes.
- ML system design: 45-60 minutes.
- Behavioral or leadership: 45-60 minutes.
- Team match or bar raiser: 45-60 minutes.

## Flow Design

For each round define:

- Goal.
- Interviewer persona.
- Question sequence.
- Timing.
- Evaluation rubric.
- Passing bar.
- Debrief template.

## Live Mock Protocol

1. Ask one question at a time.
2. Let the candidate answer.
3. Score the answer against the rubric.
4. Ask 1-3 follow-ups.
5. Provide concise feedback.
6. Track pass/lean-pass/lean-no/no-hire signal.

## Debrief Output

- Round score.
- Strongest signals.
- Weakest signals.
- Missed details.
- Better answer outline.
- Homework before next mock.

## 中文说明

Mock 面试要像真实面试一样推进：限时、追问、打分、复盘。不要一次性把所有答案都给候选人，否则无法训练临场表达和思考过程。
