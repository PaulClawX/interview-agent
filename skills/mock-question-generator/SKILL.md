# Mock Question Generator Skill / Mock 面试题生成 Skill

Use this skill to generate realistic AI interview questions from research, resume, and target role.

## Research Requirement

For company-specific questions, search recent public interview experiences and official prep material first. Include citations and mark anecdotal questions clearly.

## Question Categories

- Coding: arrays, graphs, dynamic programming, concurrency, data processing, Python/C++ implementation.
- ML fundamentals: bias-variance, regularization, optimization, loss functions, calibration, embeddings, transformers, attention, diffusion, RL, evaluation.
- ML system design: recommendation, ranking, search, ads, RAG, agent systems, multimodal serving, feature stores, training pipelines, online/offline evaluation, A/B tests.
- LLM and agents: prompt pipelines, tool use, memory, retrieval, evaluation, safety, latency, cost, observability, guardrails.
- AI infra: distributed training, GPU memory, inference optimization, batching, quantization, model serving, data pipelines.
- Research deep dive: paper contribution, baselines, ablations, limitations, reproducibility, future work.
- Behavioral: conflict, ambiguity, leadership, failure, prioritization, collaboration, ethical judgment.
- Resume deep dive: every major claim should have follow-up questions.

## Difficulty Levels

- L3/L4 or campus: fundamentals, implementation clarity, learning velocity.
- L5/E5/senior: ownership, system design, tradeoffs, production judgment.
- L6+/staff: strategy, cross-team influence, technical direction, ambiguous problem solving.

## Output Format

For each question include:

- Question.
- Why it is likely.
- Expected signal.
- Strong answer rubric.
- Follow-up questions.
- Common failure modes.
- Timebox.

## 中文说明

题目要来自岗位、公司、简历和公开面经的交集。不要只生成泛泛的“Transformer 是什么”；要加入场景、约束、追问和评分标准。
